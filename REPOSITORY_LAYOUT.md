# Repository layout and frozen publication package

This repository contains the compact visuotactile world-model study at its root.
The scientific source and recorded result files retain the bytes from the arXiv
ancillary package. The package's README.md is named README_reproduction.md here
so the repository can have a separate landing page.

FILES_SHA256.json maps that one filename and verifies the same 205 payload files.
ARXIV_FILES_SHA256.json preserves the original package index. SOURCE_MANIFEST.json
and PACKAGING_CHANGES.md continue to document the earlier source-to-archive step.
The ZIP at paper/arxiv_source.zip remains byte-identical to the prepared upload.

README.md, INSTALL.md, the dependency lists, CITATION.cff, repository configuration,
this note, and paper/README.md are repository documentation. No experimental result
has been recalculated or replaced as part of moving these files.
